Moving on from Yenka?

Many Engineering Science departments have used Yenka for circuit and control simulation. Sumdog, who now publish Yenka, have announced that Yenka is being withdrawn:

  • From 31 December 2026, Yenka products will no longer be sold, and new hobbyist (home) licences will not be available.
  • All technical support ends on the same date.
  • Existing licences will keep working on the same terms as now, but there will be no further updates and no guarantee that Yenka will keep working with future versions of Windows or school IT systems.

If your department needs a replacement, the simulators above cover the same course content and run in a web browser, with nothing to install:

  • Analogue circuits (meters, sensors, transistors, MOSFETs, op-amps): NoResistanceSim
  • Digital logic: NoNANDSenseSim
  • Flowcharts and programmable control: NoSyntaxSim
  • Pneumatics: No Pressure Sim, which is verified by Qualifications Scotland for use in Engineering Science assignments

Each simulator is already built into the matching ESS course notes, so pupils use the same tool in class, for homework and for assignment practice.
