Simulators

Every simulator used on Engineering Science Scotland, the version we use, and where to find the latest release.

ESS uses a checked copy of each simulator, so that it matches the course notes and the simulators built into them. If a newer version has been released, you’ll find it on the NoStrain Simulation site.

Latest releases: the NoStrain Simulation site always has the newest version of each simulator, together with its user guide.
