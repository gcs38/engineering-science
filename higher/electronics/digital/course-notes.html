Six logic gates, Boolean expressions, truth tables, design from a specification and NAND equivalents

Before you start. This topic builds on National 5, where you met NOT, AND and OR gates, truth tables and Boolean expressions. At Higher you add the NAND, NOR and EOR gates, work with up to four inputs, and learn to build any circuit from NAND gates alone. To revise, use the National 5 Digital Electronics notes.

Section 1: Digital Signals and Logic Levels

In Analogue Electronics, a sensor voltage divider produced an analogue signal: a voltage that can take any value between 0 V and the supply, changing smoothly as the light or temperature changes. That gives fine control, but many control decisions only need to know whether something is on or off.

A digital signal has only two states. Rather than working with actual voltages, we call the low state logic 0 and the high state logic 1. A comparator is a common way to turn an analogue sensor signal into a digital one: its output is either high or low depending on whether the sensor voltage is above or below a reference.

Analogue signalDigital signal
Valuesany value within a rangeonly two: logic 0 and logic 1
Exampleoutput of a thermistor voltage divideroutput of a comparator, a push switch or a logic gate
Best formeasuring how muchdeciding yes or no
A digital electronic system is often called a logic system. Its signals are combined using logic gates.

Gates with three or four inputs

AND, OR, NAND and NOR gates can have more than two inputs, and exam questions use up to four. They follow exactly the same rules: a 4-input AND gate gives 1 only when all four inputs are 1; a 3-input NOR gate gives 1 only when all three inputs are 0. A 3-input AND is written Z = A · B · C.

How many rows? Every extra input doubles the number of rows in a truth table: 2 inputs → 4 rows, 3 inputs → 8 rows, 4 inputs → 16 rows. Always list the inputs by counting up in binary from 0000 to 1111.

Section 3: Boolean Notation

Boolean algebra is a short way of writing what a logic circuit does. You must use the notation exactly, because one misplaced bar changes the meaning.

+ means OR, not add. In Boolean algebra 1 + 1 = 1.

Where the bar goes matters

A bar over a whole expression means the whole result is inverted (a NAND or NOR). A bar over each letter means each input is inverted first. These are not the same:

The two right-hand columns differ in two rows, so A · B ≠ A · B.

Use brackets to show which parts belong together, e.g. Z = (A · B) + (B · C). Markers look for brackets in the right place. You do not need to simplify expressions at Higher.

Section 4: Analysing Logic Circuits

A circuit made from several gates is a combinational logic circuit. Exam questions often give you the logic diagram and ask you to complete a truth table — usually with columns for points inside the circuit — and to write its Boolean expression.

  • Label the output of each gate (D, E, F…) before you start. Use letters that are not already inputs.
  • Fill in one column at a time, working from the inputs towards the output. Each column only depends on the columns feeding that gate.
  • Build the Boolean expression the same way: write an expression for each labelled point, then substitute. Your final answer must use only the inputs.
Worked example — truth table and Boolean expression
1
Column D is the NOT gate: D = A, so D is the opposite of A.
2
Column E is the AND gate fed by D and B: E = 1 only where D = 1 and B = 1. So E = A · B.
3
Column Z is the NOR gate fed by E and C: Z = 1 only where E = 0 and C = 0.

Boolean expression: Z = (A · B) + C

Section 5: Boolean Expressions from Truth Tables

Sometimes you are given a truth table and asked for the Boolean expression. Use the sum of products method:

  • Find every row where the output is 1.
  • For each of those rows, AND the inputs together, putting a bar over any input that is 0 in that row.
  • OR all of these terms together, using brackets around each term.

Section 7: NAND Equivalent Circuits

Logic gates are bought as integrated circuits (ICs), each containing several gates of one type. A circuit needing one AND, one OR and one NOT gate would need three different ICs, most of whose gates would sit unused.

Any logic function can be built from NAND gates only. Using a single type of gate means:

  • only one type of IC (the 7400, which contains four 2-input NAND gates) needs to be bought and stocked — and it can be bought in bulk, so it is cheaper;
  • fewer ICs are often needed, so the circuit board is smaller and cheaper to make;
  • assembly is simpler, with fewer different parts.

Converting a circuit: three stages

  • Stage 1: replace every gate with its full NAND equivalent.
  • Stage 2: connect them up exactly as in the original circuit.
  • Stage 3: look for two NAND inverters in a row. Two inverters cancel each other out, so remove both. Show this by crossing them out — do not simplify in your head.
Double inverters appear wherever an AND (which ends with an inverter) feeds an OR (which starts with inverters). Look there first.

Section 8: Logic ICs and Practical Circuits

Logic gates are built into 14-pin ICs. In the 7400 family, pin 14 connects to +VCC (5 V) and pin 7 to 0 V. Common ICs:

ICContents

7486four 2-input EOR gates

7427three 3-input NOR gates

TTL and CMOS

7400 series (TTL)4000 series (CMOS)
Supply voltage5 V only (4.75–5.25 V)wide range, about 3–15 V
Power usehighervery low — good for batteries
Output currentcan drive an LED directlysmall; may need a driver

Connecting an LED: source and sink

  • Source: LED and resistor from the output to 0 V. Current flows out of the gate, so the LED lights when the output is 1.
  • Sink: LED and resistor from +VCC to the output. Current flows into the gate, so the LED lights when the output is 0.

The series resistor drops the voltage the LED does not use: R = (Vsupply − VLED) / ILED. For higher-current loads such as motors or relays, the gate drives a transistor or MOSFET, as in Analogue Electronics.

Section 9: Design Challenges

Each challenge gives a real context and a written specification. Work through the same stages as the Higher assignment: analyse, design, build or simulate, test and evaluate.

How to approach these: decide what logic 1 and 0 mean for every input and output. Write the truth table first, then the Boolean expression, then the logic diagram. Convert to NAND gates and count the ICs. In your evaluation, refer back to every numbered point in the specification.
